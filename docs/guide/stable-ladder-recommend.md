## 一、 为什么很多梯子白天很快，一到晚上 9 点就严重卡顿？

很多用户常有这样的疑惑：“为什么下午测速能跑几百兆，一到晚上打游戏、看 4K 或者远程办公就疯狂卡顿转圈？”

这背后的技术真相是**公网国际出口拥塞与运营商激进的 QoS（服务质量）策略**：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   【晚高峰 20:30 - 23:30 链路流量实测对决】            │
├────────────────────────────────┬───────────────────────────────────────┤
│ 普通公网中继 / 直连公网        │ 企业级物理专线 (IPLC / IEPL)          │
├────────────────────────────────┼───────────────────────────────────────┤
│ 1. 数据走公网海底光缆出口      │ 1. 数据走内网局域网私有物理光缆       │
│ 2. 晚高峰出口总带宽打满严重堵塞│ 2. 物理独享内网通道，完全不走公网出口 │
│ 3. 运营商强制触发 QoS 随机丢包 │ 3. 无视公网波动，晚高峰全天丢包率 < 0.1%│
│ 4. TCP 窗口指数级退避断流      │ 4. 延迟抖动标准差 StdDev < 1.2ms      │
└────────────────────────────────┴───────────────────────────────────────┘
```

### 1. 公网骨干网的“沙丁鱼罐头”效应
每天晚上 8 点半至 11 点半，国内数以亿计的流量涌向国际互联网出口。普通中继服务商使用的是普通民用公网骨干网络，当总出口带宽被占满时，运营商路由器会执行严格的丢包策略，导致普通梯子的丢包率从白天的 1% 瞬间飙升至 **15% - 30%**。

### 2. TCP 协议的恶性循环
Shadowsocks / VMess / Trojan 普遍基于标准 TCP 协议。TCP 一旦嗅探到链路丢包，为了防止网络崩溃，会自动将数据滑动窗口缩小 50% 并强制退避重传。这就导致原本高速传输的视频流瞬间断崖式降速，用户直观感受就是“视频卡死转圈、网页打不开”。

### 3. 物理专线（IPLC / IEPL）的技术降维打击
真正能够做到**稳定率最高、晚高峰不卡顿**的梯子，底层无一例外采用 **IPLC（国际私有租用线路）或 IEPL（国际以太网专线）**。
- **内网点对点光纤**：客户端将数据发送至国内 BGP 入口机房后，直接进入运营商的跨国内网私有物理光纤，直达香港、日本或新加坡机房。
- **不过公网出口**：传输过程根本不经过公网国际网关与公网防火墙，完全避开公网高峰期拥堵，全天 24 小时保持 `0.0% - 0.1%` 的极致低丢包率。

## 二、 衡量“高质量稳定的梯子”的 3 大硬核评测标准

在 NodeLadder Lab 的评测体系中，评价一款梯子是否足够稳定，严格依据以下三大硬指标：

1. **晚高峰延迟抖动标准差（Jitter & StdDev `< 2.0ms`）**：
   - 很多新手只看 Ping 值大小（如 30ms），却忽略了抖动。如果一会儿 30ms、一会儿 150ms，那就是严重抖动；真正稳定的专线，连续 ping 10,000 次，延迟波动范围极小，标准差必须控制在 1.5ms 以内。
2. **三网 BGP 边缘冗余调度（电信/联通/移动多入口）**：
   - 国内三大运营商之间的跨网互联延迟极大。优秀的专线梯子必须部署广州、深圳、上海、北京多地多线 BGP 节点，电信走电信优化、移动走移动内网，单点割接时能够秒级无感热备。
3. **拒绝虚高倍率与超卖（1.0x 真实透明计费）**：
   - 部分劣质商家为了低价吸客，把 100 人的服务器超卖给 5000 人，晚高峰带宽瞬间见底。稳定率最高的梯子必须拥有充足的单节点带宽储备（1Gbps - 2.5Gbps 物理管道），且执行 1.0x 真实倍率。

## 四、 选购避坑总结：三看三不看

选购高质量稳定的梯子时，请牢记以下法则：

- **一看**：看是否承诺真正的 **IPLC / IEPL 内网专线**（无视公网 QoS）；
- **二看**：看是否具备 **多入口 BGP 容灾**（单点维护不掉线）；
- **三看**：看计费倍率是否 **真实透明 1.0x**（无隐式刺客扣费）；
- **不看**：不看非高峰期（白天）虚高的单线程跑分；
- **不看**：不看“9.9 元买断一年”的超卖跑路低价噱头；
- **不看**：不看号称成百上千个冷门节点的虚幻数量（主力节点稳定才是王道）。
