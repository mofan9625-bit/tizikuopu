# 什么是规则分流与 TUN 模式？全局代理与绕过大陆的区别及避坑指南

许多新手刚下载了 Clash、Sing-box 或 Shadowrocket，看到设置界面里的各种模式瞬间头大：**“规则模式（Rule）”、“全局代理（Global）”、“直连模式（Direct）”、“TUN 模式”到底是什么意思？为什么长期开全局代理会导致微信被封号、网银 App 报错、国内看 B 站慢如蜗牛？”**

代理客户端不仅是一个连接工具，更是一个精密的**网络流量分流路由器**。理解规则分流与 TUN 模式的底层逻辑，是每一个跨境网络用户保障网络安全、兼顾速度与避免封号的核心技能。本文由 **NodeLadder Lab** 技术实验室带来最透彻的实操原理拆解。

## 一、为什么现代代理客户端能够实现“国内直连，国外翻墙”？

传统的商业 VPN（如 OpenVPN）之所以体验糟糕，是因为它采用了**“一刀切”的系统默认网关接管**——只要开启，整台电脑包括看优酷、刷淘宝、登网银的所有数据包，全部强制绕道海外机房再绕回国内，造成极大的延迟和带宽浪费。

而现代代理客户端（Clash Meta / Mihomo、Sing-box）基于 **规则路由引擎（Rule-based Proxy Engine）**，在本地对发出的每一个网络数据包进行实时嗅探与智能分流：

```text
[用户发起网络请求]
        │
        ▼
[客户端本地分流规则匹配引擎]
        ├── 目标域名包含 .cn / 属于中国 IP 地址库 (GeoIP: CN) ──> DIRECT (直连本地互联网，零延迟)
        ├── 目标属于广告库 / 隐私追踪域名 (AdGuard / EasyList) ────> REJECT (直接丢弃拦截，免广告)
        └── 目标为 Google / GitHub / YouTube / ChatGPT ─────────> PROXY (走专线节点出境，高速秒开)
```

## 二、三大核心运行模式对比：规则、全局与直连

| 代理模式 | 流量路由机制 | 对国内应用/网速的影响 | 对海外跨境应用的影响 | 核心推荐度与场景 |
| :--- | :--- | :--- | :--- | :--- |
| **规则模式 (Rule)** | **按预设规则集智能分流**（国内走直连，国外走代理） | **毫无影响**（国内网站本地跑满千兆带宽） | **平稳高速**（自动走对应地区的专线） | ⭐⭐⭐⭐⭐ **日常 100% 推荐使用** |
| **全局模式 (Global)**| **不分青红皂白，所有流量统统强制走选定节点** | **严重负面**（国内软件绕道海外，被风控报警） | 全部强制走单一节点 | ⭐⭐☆ 仅用于临时排障或特定测试 |
| **直连模式 (Direct)**| 所有流量全部直接连公网，相当于关闭代理 | 恢复裸连公网状态 | 无法访问受阻海外网站 | ⭐ 仅用于完全停用代理排查故障 |

### ⚠️ 为什么强烈警告：日常千万不要长期开启“全局模式（Global）”？
1. **微信与网银异地风控**：微信、支付宝、各大银行 App 检测到你的登录 IP 瞬间从北京跳到香港机房，会立刻触发异常异地登录安全警报，甚至冻结账户要求人脸识别；
2. **版权与 CDN 误判**：腾讯视频、爱奇艺、网易云音乐等平台检测到非大陆 IP，会直接提示“由于版权限制，您所在的地区无法播放”；
3. **严重浪费机场流量**：看国内 4K 视频、下载国内网盘几百 GB 的文件全走梯子专线，白白消耗你昂贵的国际专线月费流量。

## 三、什么是 TUN 模式？什么时候必须开启？

在客户端设置中，你经常能看到一个名为 **TUN 模式（TUN Virtual Network Adapter）** 的开关。它与系统代理有何本质区别？

### 1. 系统代理（System Proxy）的局限性
默认情况下，Clash 或 Sing-box 开启的是“系统代理（设置环境变量 `http_proxy` 与系统网络设置）”。
- **痛点**：系统代理只对**主动遵从系统代理设置的软件**（如 Chrome、Edge、Firefox 等网页浏览器）有效。
- **失效场景**：
  - Windows CMD、PowerShell、Git 命令行工具；
  - Steam / Epic / 外服游戏客户端与联机对战流量；
  - Docker 容器、VMware / VirtualBox 虚拟机、WSL2 子系统；
  - 许多使用原始 UDP 套接字通信的代码程序。
  这些软件会直接无视系统代理，继续走本地公网裸连，导致 `git clone` 经常报错、命令行 `curl` 无法访问外网。

### 2. TUN 模式的降维打击
开启 TUN 模式后，客户端会在操作系统底层虚拟出一张**全功能虚拟网卡（TUN Virtual Device）**，将操作系统的默认网关直接指向该虚拟网卡。
- **效果**：操作系统的**所有软件、所有端口、所有 UDP/TCP 流量**，在进入网络物理层之前都会被该虚拟网卡无缝拦截并送入规则路由引擎。
- **优点**：彻底解决 Git 报错、终端命令行无法联网、游戏无法加速的世纪难题，真正实现“全系统无死角透明代理”。

## 四、极客最佳实操避坑建议

1. **日常挂后台首选配置**：
   - 保持 **“规则模式（Rule）”**；
   - 开启 **“TUN 模式”**（同时勾选自动管理防火墙与自动设置默认路由）；
   - 开启 **“DNS 智能防污染与域名嗅探（Sniffer）”**，防止本地 DNS 缓存污染导致连不上网。
2. **分流策略组微调**：
   - 将 `ChatGPT / Claude` 分配到低风控美区或日区专线节点（推荐纯净原生 IP 专线，如 [**云界线**](/reviews/yunjiexian-review) 或 [**环球梯**](/reviews/huanqiuti-review)）；
   - 将日常海外冲浪与 YouTube 4K 播放分配到低延迟深港专线节点（如 [**大佬云**](/reviews/dalaoyun)）；
3. **查阅各客户端极客进阶配置教程**：
   - 详细配置步骤请参阅 [《Clash Meta / Mihomo 进阶分流教程》](/clients/clash) 与 [《Sing-box 规则集全平台配置指南》](/clients/sing-box)。

## 💡 极客网络高频 FAQ 问答

### Q1: 开启 TUN 模式后，为什么局域网打印机或 NAS 突然连不上了？
**答**：因为 TUN 模式接管了全网卡流量。解决方法是在客户端设置中开启“局域网直连（Bypass LAN）”，将 `192.168.0.0/16`、`10.0.0.0/8` 等内网私有网段排除在虚拟网卡之外，避免内网包被误送入代理隧道。

### Q2: 既然规则分流很好，为什么偶尔还要用到全局代理（Global）？
**答**：部分极小众的海外网站或未收录进 GeoIP / 域名规则集的新域名，可能会被规则引擎误判为直连而打不开。此时切到全局模式可快速排查是否为规则库漏收录。排查完毕后务必切回规则模式。

### Q3: 很多用户反映开启代理后微信聊天有延迟或偶尔收不到消息，怎么解决？
**答**：检查分流规则中是否将微信所属域名（`qq.com`、`servicewechat.com`）正确匹配为 DIRECT 直连，避免国内长连接数据包绕道海外专线产生心跳超时。更多规则优化技巧请参考 [《FAQ 常见报错与分流规则指南》](/faq/rules)。
