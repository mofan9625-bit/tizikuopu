# Kimi (月之暗面) 深度使用指南：200万字长文本研读、PDF解析与直连优化

**Kimi** 是由月之暗面（Moonshot AI）推出的现代化大语言模型助手。它以**支持高达 200 万字无损上下文**打破了全球大模型的长文本纪录，在超长长文本分析、学术论文研读、法律卷宗梳理与复杂财报解读中展现出极强的国产大模型实力。

## 二、国内访问网络环境与直连分流配置

Kimi 服务器主要部署在境内机房，国内用户访问无需经过海外代理节点。但若客户端开启了全局代理，可能导致流量绕道海外产生额外延迟。

### 1. 痛点成因分析
- **代理绕路延迟**：开启 Global 全局代理后，访问 `kimi.moonshot.cn` 的流量误经海外中继，引发网页加载拖拽感。
- **DNS 污染防护**：避免本地 DNS 解析错误引发的站点连通性波动。

### 2. 极客规则分流配置 (Clash / Sing-box)
建议在代理软件的规则库中加入 `DIRECT` 直连豁免规则，确保 Kimi 流量直接走本地宽带：

```yaml
rules:
  # Kimi (月之暗面) 国内直连豁免规则
  - DOMAIN-KEYWORD,moonshot,DIRECT
  - DOMAIN-SUFFIX,kimi.moonshot.cn,DIRECT
  - DOMAIN-SUFFIX,moonshot.cn,DIRECT
```

## 三、账号注册与使用避坑全流程

### 1. 注册与登录全流程
1. 打开官网 [kimi.moonshot.cn](https://kimi.moonshot.cn)。
2. 支持国内手机号验证码一键注册登录，或通过微信快捷扫码认证。

### 2. 3 大长文本处理避坑法则
- **法则 1：清晰标注提炼范围**：上传数百页大文件时，建议在 Prompt 中明确指出“请重点分析第四章与第六章的数据”。
- **法则 2：结构化输出要求**：要求 Kimi 使用表格或思维导图 Markdown 语法输出，可极大提升研读效率。
- **法则 3：防止大文件解析卡顿**：扫描版 PDF 建议先通过 OCR 转化为矢量文本后再导入 Kimi。

## 五、高频报错与排障 FAQ

### Q1: 提示“上传文件过大或解析超时”怎么办？
**答**：这通常是因为上传了纯图片扫描件 PDF。建议使用工具将 PDF 进行文本化处理，或将超大文件拆分为多个子文档分批导入。

### Q2: 开启代理软件后 Kimi 网页无法加载或提示连接中断？
**答**：说明代理软件的全局模式导致流量绕道海外。请在客户端规则中将 `kimi.moonshot.cn` 添加至 `DIRECT` 直连列表。
